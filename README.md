# クリエアイ AI×Webデザインスクール LP（ポートフォリオ）

架空のスクール「クリエアイ」の広告ランディングページです。ポートフォリオ用の制作物で、実在の団体・サービスではなく、お申し込みはできません。

公開ページ: https://asam06976-rgb.github.io/creai-school-lp/

## 制作意図
- ターゲット: 未経験からAI×Webデザインを学びたい20〜30代女性
- 構成: ファーストビュー → 不安の解消 → AI活用の具体像 → 特典 → 選ばれる理由 → 学習の流れ → サポート → カリキュラム → 作品・受講生の声 → 比較 → 料金 → FAQ → メッセージ（広告LPの定石構成）
- デザイン: 白地にペリウィンクル×コーラルのグラデーションで「明るい未来」を想起させる配色。切り抜き人物とオリジナルのAI相棒キャラで親しみやすさを出す

## 使用技術
- HTML / CSS / JavaScript（フレームワーク不使用）
- レスポンシブ対応（PC・タブレット・スマホ）
- カリキュラムの手動横スクロール（スクロールスナップ・矢印・ドラッグ）、受講生の声の自動カルーセル、料金タブ、FAQ開閉、固定CTA
- 画像はすべて生成画像（実在の人物・ブランドなし）。WebP形式で軽量化
- 写真に代替テキストを付与
